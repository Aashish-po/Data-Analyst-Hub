# Data Analyst Roadmap

A structured, 26-topic learning roadmap designed to take aspiring data analysts from foundational knowledge to job-ready in **20 weeks**. This repository contains the complete roadmap as an interactive HTML page, a curated resource list in Markdown, and supporting files for tracking progress.

> **Target audience:** Beginners with basic Python and Excel familiarity  
> **Philosophy:** Free-first — the entire roadmap can be completed for $0  
> **Last updated:** July 2025 (all links verified)

---

## 🎯 Career Path Overview

This roadmap covers the **end-to-end data analyst skill set** across six progressive phases:

| Phase | Duration | Focus |
|-------|----------|-------|
| **1. Foundations** | Weeks 1–3 | Data literacy, Excel, statistics, Python basics, ethics |
| **2. Core Tools** | Weeks 4–7 | SQL, visualization principles, Python viz, Tableau, Power BI |
| **3. Analysis Skills** | Weeks 8–12 | Data cleaning, EDA, applied statistics, A/B testing, metrics, cohort/funnel analysis |
| **4. BI & Professional Skills** | Weeks 10–14 | Intermediate Tableau/Power BI, communication, storytelling, project management |
| **5. Portfolio** | Weeks 13–17 | Domain specialization, two end-to-end projects, GitHub/LinkedIn polish |
| **6. Job Readiness** | Weeks 16–20 | SQL drilling, case studies, statistics review, product sense, behavioural prep |

**Total:** 26 topics · 6 phases · 20 weeks · ~20 hrs/week

---

## 📚 Core Milestones & Skill Areas

### Phase 1 — Foundations (Weeks 1–3)

- **01 Data Fundamentals** — Data types, structures, pipelines (ETL), sources
- **02 Excel for Data Analysis** — PivotTables, XLOOKUP, Power Query, dynamic arrays
- **03 Statistics Fundamentals** — Descriptive stats, distributions, CLT, hypothesis testing, p-values
- **04 Python for Data Analysis** — pandas, NumPy, Jupyter, data wrangling
- **05 Data Ethics** — Bias, privacy (GDPR/CCPA), PII, responsible visualization

### Phase 2 — Core Tools (Weeks 4–7)

- **06 SQL Basics** — SELECT, JOINs, GROUP BY, subqueries (most-tested interview skill)
- **07 SQL Advanced** — Window functions, CTEs, optimization, indexes
- **08 Data Visualization Principles** — Chart selection, Gestalt principles, color theory, accessibility
- **09 Python Visualization** — matplotlib, seaborn, plotly
- **10 Business Intelligence Tools** — Tableau Public + Tableau Public & Power BI Desktop fundamentals

### Phase 3 — Analysis Skills (Weeks 8–12)

- **11 Data Cleaning & Preparation** — Missing values, outliers, tidy data principles, OpenRefine
- **12 Exploratory Data Analysis (EDA)** — Repeatable framework, ydata-profiling, Titanic case study
- **13 Statistical Analysis Applied** — scipy.stats, statsmodels, regression, correlation
- **14 A/B Testing & Experimentation** — Design, power analysis, Evan Miller calculator
- **15 Business Metrics & KPIs** — DAU/MAU, retention, LTV, CAC, SaaS metrics
- **16 Cohort & Funnel Analysis** — Retention heatmaps, drop-off analysis, Mixpanel/Amplitude

### Phase 4 — BI & Professional Skills (Weeks 10–14)

- **17 Tableau — Intermediate** — LOD expressions, table calculations, performance
- **18 Power BI — Intermediate** — DAX (CALCULATE, SUMX, RANKX), time intelligence
- **19 Communication Skills** — Pyramid Principle, SCQA, executive summaries
- **20 Storytelling with Data** — Makeover Monday, narrative structure, cognitive load
- **21 Project Management** — Agile/Scrum, RICE prioritization, stakeholder management

### Phase 5 — Portfolio (Weeks 13–17)

- **22 Domain Specialisation** — SaaS/Product, E-Commerce, or Fintech
- **23 Portfolio Project I** — End-to-end EDA + insight report on GitHub
- **24 Portfolio Project II** — SQL queries + published BI dashboard
- **25 Portfolio Presentation & GitHub** — README, LinkedIn, resume optimization

### Phase 6 — Job Readiness (Weeks 16–20)

- **26 Interview Preparation** — SQL drilling, take-home cases, statistics, product sense, STAR method

## 🚀 Viewing the Roadmap Locally

### Option 1: Direct Browser Open (Simplest)

```bash
# Navigate to the project directory
cd Data-Analyst

# Open the HTML file directly in your default browser
# Windows:
start data_analyst_roadmap.html

# macOS:
open data_analyst_roadmap.html

# Linux:
xdg-open data_analyst_roadmap.html
```

### Option 2: Local Web Server (Recommended for Full Functionality)

The roadmap includes navigation to other pages (`index.html`, `resources.html`, etc.) which require a local server due to CORS restrictions.

**Using Python (built-in):**

```bash
cd Data-Analyst
python -m http.server 8000
# Then open http://localhost:8000/data_analyst_roadmap.html
```

**Using Node.js (if installed):**

```bash
cd Data-Analyst
npx serve .
# Then open the provided URL
```

**Using VS Code Live Server Extension:**

1. Install "Live Server" extension
2. Right-click `data_analyst_roadmap.html` → "Open with Live Server"
