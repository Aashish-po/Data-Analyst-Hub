Full Roadmap

From Zero to Data Analyst

A structured, 26-topic learning roadmap for beginners with basic Python and Excel knowledge, optimised for landing a job in under 5 months.

26 Topics · 6 Phases · 20 Weeks

Each phase builds on the previous one. Phases 3–5 intentionally overlap — begin portfolio projects while deepening analysis skills.

Phase 1 — Foundations

Weeks 1–3
01 Data Fundamentals

Understand structured vs. unstructured data, CSV/JSON/databases, data pipelines (ETL), and how data flows from collection to insight.

Coursera — Google Data Analytics Data Literacy Project
02 Excel for Data Analysis

PivotTables, XLOOKUP, dynamic arrays, Power Query for ETL, data validation, and conditional formatting for analysis.

ExcelJet Chandoo — PivotTables
03 Statistics Fundamentals

Mean, median, mode, variance, std deviation, normal distribution, CLT, p-values, confidence intervals, t-test, chi-square.

StatQuest (YouTube) Khan Academy
04 Python for Data Analysis

pandas DataFrames: load, inspect, filter, sort, groupby, merge, pivot. NumPy arrays and vectorised operations.

Kaggle — Pandas pandas Docs
05 Data Ethics

Algorithmic bias, data privacy laws (GDPR, CCPA), PII handling, informed consent, avoiding misleading visualisations.

The Markup LinkedIn Learning

Phase 2 — Core Tools

Weeks 4–7
06 SQL Basics

SELECT, WHERE, JOIN (all types), GROUP BY, HAVING, ORDER BY, subqueries. The most-tested skill in DA interviews.

Mode SQL Tutorial SQLZoo
07 SQL Advanced

Window functions (ROW_NUMBER, RANK, LAG, LEAD), CTEs, recursive CTEs, CASE WHEN, query optimisation, indexes.

pgexercises.com DataLemur
08 Data Visualization Principles

When to use bar vs. line vs. scatter vs. heatmap. Pre-attentive attributes, Gestalt principles, colour theory, accessibility.

Storytelling with Data From Data to Viz
09 Python Visualization

matplotlib for custom static charts, seaborn for statistical visuals, plotly for interactive dashboards.

Python Graph Gallery Kaggle — Data Viz
10 Business Intelligence Tools

Tableau: connect, drag-drop, calculated fields, dashboards. Power BI: Power Query, DAX basics, report pages, slicers.

Tableau Training Microsoft Learn — Power BI

Phase 3 — Analysis Skills

Weeks 8–12
11 Data Cleaning & Preparation

Systematic approach: audit → clean → validate. Handling missing values, outlier detection, string normalisation, reshaping.

Kaggle — Data Cleaning Tidy Data (Wickham)
12 Exploratory Data Analysis (EDA)

Repeatable EDA framework: shape/dtypes → nulls → distributions → correlations → outliers → time trends → bivariate analysis.

Kaggle — EDA Chapters ydata-profiling
13 Statistical Analysis Applied

Apply statistics in Python: scipy.stats for t-tests and chi-square, statsmodels for linear regression, correlation matrices.

scipy.stats Docs statsmodels Docs
14 A/B Testing & Experimentation

Design: hypothesis, control/treatment, minimum detectable effect. Power analysis. Analyse: t-tests, confidence intervals.

Evan Miller Calculator Udacity — A/B Testing
15 Business Metrics & KPIs

DAU/MAU, retention, LTV, CAC, NPS, ARPU, conversion rate, bounce rate. Know how to define, compute, and track each.

a16z — 16 Metrics Mode Analytics Blog
16 Cohort & Funnel Analysis

Cohort analysis: group users by acquisition date, track behaviour over time. Funnel analysis: step-by-step drop-off rates.

Mode — Cohort Analysis Heap — Funnel Analysis

Phase 4 — BI & Professional Skills

Weeks 10–14
17 Tableau — Intermediate

LOD expressions, table calculations, advanced dashboard design, parameters, and performance optimisation.

Tableau LOD Whitepaper Tableau Community
18 Power BI — Intermediate

Master DAX functions: CALCULATE, SUMX, RANKX. Time intelligence, relationship modelling, and performance tuning.

SQLBI — DAX Guide Microsoft — PL-300
19 Communication Skills

The Pyramid Principle, SCQA framework, writing executive summaries, presenting technical findings to non-technical audiences.

Pyramid Principle HubSpot Academy
20 Storytelling with Data

Narrative structure for data presentations, choosing the right visual for the story, reducing cognitive load.

Makeover Monday SWD Podcast
21 Project Management

Agile/Scrum basics, RICE prioritization, stakeholder management, and working effectively with engineering teams.

Atlassian Agile Coach Scrum Guide

Phase 5 — Portfolio

Weeks 13–17
22 Domain Specialisation

Pick one domain: SaaS/Product (Lenny's Newsletter, Reforge), E-Commerce (Shopify, Google Analytics), or Fintech (Investopedia, Crunchbase).

Lenny's Newsletter Shopify Analytics
23 Portfolio Project I — EDA & Insight Report

Complete end-to-end EDA project on GitHub with clean README. Use a Kaggle dataset or data.gov source.

Kaggle Datasets makeareadme.com
24 Portfolio Project II — SQL + Dashboard

10+ SQL queries on BigQuery public datasets plus a published BI dashboard on Tableau Public or Power BI Service.

BigQuery Public Datasets Tableau Public Gallery
25 Portfolio Presentation & GitHub

Polish GitHub repos, optimize LinkedIn profile, build a resume that highlights project outcomes and metrics.

Alex The Analyst Teal HQ Resume

Phase 6 — Job Readiness

Weeks 16–20
26 Interview Preparation (Full Stack)

SQL drilling (LeetCode, DataLemur, StrataScratch), take-home case studies, statistics review, product sense, and STAR behavioural prep.

LeetCode SQL DataLemur Pramp — Mock Interviews Full Interview Guide →
